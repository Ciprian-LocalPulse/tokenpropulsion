# TokenPropulsion 1.0.0rc1

An independent MIT Python project for conservative prompt formatting and transparent
evaluation. The core is dependency-free and offline by default. Includes protected
inputs, reversible audit results, CLI pipelines, optional authenticated FastAPI service,
official xAI SDK adapter, and reproducible local/explicit remote benchmark tooling.

Formatting invariants are tested; semantic equivalence is not assessed. Default counts
are estimates. No live xAI quality, cost, or latency benchmark is claimed. Live provider
compatibility and hosted CI remain release limitations; see validation.md.


## Public presentation and research documentation

- Professional 16:9 hero artwork with a 7680 x 4320 upscaled PNG export, native
  generation retained, lightweight README preview, and disclosed provenance.
- A 10,000-word English academic engineering whitepaper, with a visually reviewed
  23-page PDF, editable Markdown, bibliography, word-count verification, and renderer.
- Repository metadata, citation information, source/wheel artifacts, and checksums.

This first release is a **prerelease**. It does not assert peer review, semantic
preservation, live xAI validation, or provider savings. Hosted CI is linked separately.
