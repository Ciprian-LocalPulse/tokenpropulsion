## LinkedIn

I built TokenPropulsion, an independent open-source Python project focused on a practical
LLM infrastructure problem: reducing redundant prompt formatting without hiding what
changed or overstating the evidence.

The release candidate includes a dependency-free offline core, conservative whole-prompt
protection, mechanical validators, reversible audit records, a pipeline-friendly CLI,
an optional authenticated API, and an optional official xAI SDK adapter. Benchmarks
separate estimated local counts from provider usage and task-specific output checks.

Semantic equivalence is not assumed. Live provider results are unverified. I welcome
reproducible bug reports and critical review. MIT, by Ciprian Ștefan Pleșca.
https://github.com/Ciprian-LocalPulse/tokenpropulsion
