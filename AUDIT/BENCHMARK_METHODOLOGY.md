# Benchmark methodology

Dataset: benchmarks/datasets/evaluation.jsonl; manifest records MIT project authorship,
synthetic origin and SHA-256 7418f1d284438b60cd0a81eba84731e4a2c833ea803c320a0bb8c89ed5a96b83.
Thirty cases, fifteen categories, two per category. Eight document cases contain repeated
idempotent contexts; two lexical cases use keyword retention; twenty protected cases
exercise coding, JSON, math, Romanian, Arabic, mixed language, finance, security,
exact-format and adversarial inputs. The complex_reasoning label denotes a lexical toy,
not a reasoning evaluation. There is no real-world corpus.

Reproduce into a NEW directory:

```bash
tokenpropulsion benchmark --dataset benchmarks/datasets/evaluation.jsonl --tokenizer tiktoken --allow-tokenizer-download --repeats 10 --report fresh-results
```

Initial public vocabulary acquisition is explicit; prompt data is not transmitted.
Counting uses tiktoken cl100k_base, classified unrelated-tokenizer. Counts are exact for
that vocabulary only. Raw evidence: [optimized.json](../benchmarks/results/v2.0.0a1/optimized.json),
[baseline](../benchmarks/results/v2.0.0a1/baseline.json),
[CSV](../benchmarks/results/v2.0.0a1/comparison.csv),
[failures](../benchmarks/results/v2.0.0a1/failures.md).

No-compression, existing conservative and intentionally unsafe whitespace baselines are
recorded. The whitespace baseline never bypasses protections in production compression.
Savings are token-weighted, not a category-balanced expectation. The SVG chart is derived
from recorded counts, not invented or generated by an image model.

Ten local perf_counter observations per case provide mean, median, p50, p95, sample
variance and a normal-approximation 95% interval. Pooled timings mix input sizes;
correlated repeated measurements violate a simple independent-sample interpretation.
The mean CI is descriptive, not evidence of a population speed guarantee. Original
measurement files are preserved after subsequent transport/API hardening; these changes
do not alter local compression strategy semantics. Small nonbehavioral report writer
changes do not make the original timing a measurement of a byte-identical final tree.

Remote experiments, when authorized, alternate pair order, preflight full task contracts,
reserve worst-case retries and require exact/JSON output evaluators. No remote result,
TTFT, Grok savings or actual billed cost is reported for this release.


Review scope: internal second-pass engineering review of final code and actual outputs;
not external independent certification, peer review or production approval.
Version 2.0.0a1; baseline 1.0.0rc1. Raw execution evidence: [evidence-v2](evidence-v2/).
