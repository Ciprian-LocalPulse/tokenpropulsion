# Visual assets

`tokenpropulsion-hero-8k.png` is a 7680 x 4320 PNG export (16:9 UHD 8K).
The native AI-generated image is 1672 x 941 pixels. The 8K file is a disclosed
high-quality bicubic upscale using .NET System.Drawing, not native 8K generation.
The 1920 x 1080 JPEG is the efficient README preview. No measured-performance
claim is encoded in the illustration. The existing architecture SVG is a schematic.

Generation used the built-in image_gen tool. The exact prompt is preserved in
`image-generation-prompt.txt`; generation metadata is in `image-provenance.json`.
The native image is retained for transparent provenance. All project-original
assets are distributed with the repository's MIT license.
